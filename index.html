    你要做什么 从哪里开始 是否写入文件
    看一个仓库有哪些文件、总共多大 download --dry-run 不创建下载文件
    下载模型配置或权重 模型示例 写入选中的文件
    下载数学数据集 数据集示例 写入数据集仓库文件
    检查或安装 aria2 setup 默认只检查；安装须确认
    排查已有目录为什么被拒绝 目录与续传 不自动删除旧文件
    看命令如何映射到代码 接口树 只读说明

    最小可运行流程

    pip install ChatHFD==0.1.5
chathfd setup
chathfd download Qwen/Qwen3.8-Flash-Next --include config.json --dry-run

    上面只查询配置文件元数据，不下载模型权重。继续操作见快速开始。

    当前边界

    仅支持公开仓库；不接收或转发账号 Token。完成后按文件大小校验，不做上游密码学哈希验证。10 GiB 是文件选择的元数据预检门槛，不是网络传输的硬限额。
